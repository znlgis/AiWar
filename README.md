# AiWar

B 站 Toy 互动作品：历史战争推演 + 关键节点决策。五战：《围魏救赵》《赤壁之战》《淝水之战》《四渡赤水》《淮海战役》，共用一套确定性推演内核与「有限情报 + 关键节点决策」框架，每场战役有独立地图、部队、节点、敌方 AI 与评分结局。

玩家只能看到前线军报（有来源、有送达延迟、有可信度）与最新势力范围；战场由推演内核与敌方 AI 决定，结局不必与史书相同。单局约 5–8 分钟（推演约 2 秒/日，决策时自动暂停）。

## 玩法

- **五场战役，同一套规则**：战国（围魏救赵）、三国（赤壁）、东晋（淝水）、长征（四渡赤水）、解放战争（淮海）；战役之间共享内核，词表与难度参数各自独立
- **关键节点**：7–8 个条件触发的决策（出兵方略、平陵示弱、邯郸危局、大梁震动、回师伏击、战后处置……），每个节点 2–4 个取舍，逾时按难度执行默认方案
- **军令牌**：节点之间每 8 日回 1 枚（上限 3 枚），行军、佯动、强攻、设伏、休整、筹粮、侦察、渡河各消耗 1 枚（驻守不耗）
- **军令真的会生效**：侦察会揭开周边城邑并提高情报命中率；筹粮按城内存粮补充军粮；渡河会拖慢部队但能过河；无舟楫走水路、无路可走时会给一条「军令已废」的回执，而不是静默丢令
- **情报有噪声**：难度越高，兵力读数越糊、假情报越多、送达越慢；同一件事可能被不同来源说成两样。势力图上只显示已探明信息与敌军最后出现位置
- **地图**：视野按战役地图尺寸自适应，可拖动平移、滚轮/双指缩放、双击复位
- **音效**：WebAudio 合成（战鼓、号角、简牍、胜负），无音频文件，顶栏可一键静音
- **难度**：改变情报质量、决策窗口与关键事件（风向、敌军是否自乱）的走势，并给高难度少量评分加成；不给敌方兵力数值加成
- **结算**：S/A/B/C/D 评级、战果分档（不写精确伤亡）、关键决策时间轴与史实对照

## 开发

```bash
pnpm install
pnpm dev          # 本地开发
pnpm test         # 内核、平衡与回归测试
pnpm build        # 构建 apps/site/dist
pnpm toy:zip      # 打包 release/aiwar-guiling.zip（包根 index.html）
pnpm toy:check    # Toy 发布自检（check-toy.mjs）
pnpm check        # typecheck + test + build + zip + check
```

回归测试锁定三条底线：**每场战役的史实路线必须能打到 A/B 以上**、**史实难度得分不得低于地狱难度**、**同一 seed 与同一串决策必须复现同一结局**。改平衡参数后先跑 `pnpm test`，不要直接改断言。

本地按 Toy 子路径预览（验证相对路径不白屏）：

```bash
pnpm build && pnpm preview:toy   # http://127.0.0.1:4173/toy/aiwar-guiling/index.html
```

预览跑着时，可以做一次真机渲染冒烟（需要本机有 Edge 或 Chrome）：

```bash
node scripts/smoke-render.mjs    # 自动找浏览器；截图落在 .shots/，有报错则退出码非 0
```

它检查 Vue 是否真的挂载、地图/战报是否渲染出内容、速度控件是否按 ×1→×2→×4 循环，并收集控制台异常。

## 目录

```
apps/site/          # Toy 站点（Vue 3 + Vite + TS，运行时只依赖 Vue）
packages/sim/       # 纯 TS 推演内核（确定性随机、战斗、围城、情报、AI、评分）
packages/content/   # 战役数据与战报语料
scripts/            # 发布自检、zip、子路径预览、截图/试玩（开发用）、物料生成
docs/               # 方案、设计、技术、合规、开发计划
release/            # 发布物料：aiwar-guiling.zip、poster.png、icon.png
```

## 发布

`release/aiwar-guiling.zip` 直接上传即可（ZIP 根目录为 index.html，整包约 157 KB）。封面 `release/poster.png`（1200×900，4:3），图标 `release/icon.png`（512×512）按发布页要求填写。
